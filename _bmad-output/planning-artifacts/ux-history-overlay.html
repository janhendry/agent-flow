Tastatur-Navigation: Die Demo ist vollständig keyboard-bedienbar. Klicke auf das Overlay um den Fokus zu aktivieren, dann Pfeiltasten + Enter. Enter auf einem Eintrag kopiert den Text in die Zwischenablage (Toast erscheint). ESC schließt das Overlay — Klick auf die Stage öffnet es wieder. Fuzzy Search: Tippe z.B. mtng für „meeting" oder cmmt für „commit".
